
## 三條攻擊線

| 線 | 方向 | 核心問題 |
|----|------|---------|
| α | Li 準則 | λ_n 為何全正？有沒有結構性原因？ |

## 三道關卡（每個想法必過）

1. **Epstein 測試**：這個論證對 Epstein zeta 也成立嗎？→ 是則死路
2. **Euler 乘積測試**：有用到質數的乘法結構嗎？→ 有則好跡象
3. **邏輯測試**：有明顯漏洞嗎？
