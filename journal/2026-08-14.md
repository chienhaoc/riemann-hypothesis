## 關鍵發現

### 發現 1：「剛好為真」困境的精確表述

RH 無法用一般解析方法證明，因為：

- Epstein zeta 函數擁有函數方程、解析延拓、臨界帶——但零點不在臨界線
- 任何只依賴「函數方程 + 成長階 + 解析性質」的方法必然失敗
- **測試工具**：每個想法必須問「這個論證對 Epstein zeta 也成立嗎？」

### 發現 2：Li 係數的 Weil 分解

$$\lambda_n = \underbrace{\lambda_n^{(\infty)}}_{\text{Gamma 項，}\approx \frac{1}{2}n\ln n} + \underbrace{\lambda_n^{(f)}}_{-\sum_p \frac{\ln p}{\sqrt{p^k}} W_n(k\ln p)}$$

- **阿基米德項**（函數方程）：提供正向成長的「背景值」
- **算術項**（Euler 乘積）：質數試圖把 λₙ 拉向負值
- RH 本質 = 這兩項的「永恆拔河」，算術項永遠輸

### 發現 3：Beurling 實驗的量化結果

- 臨界偏差 **δ* ≡ ε**，其中零點偏離為 Re(ρ) = 1/2 + ε
- 任何 δ > 0，無論多小，最終都會讓某個 λₙ 變負
- **沒有任何已知定理**能無條件保證真實質數偏差 < δ*
- 這就是 RH 為何是千禧年難題的精確原因

### 發現 4：算子的最小需求清單

| 條件 | 狀態 |
|------|------|
| 希爾伯特空間 H | ✅ 已知（Adeles 上的 L² 空間）|
| 對稱算子 T | ✅ 已知（Connes 的縮放算子）|
| 跡公式對應 | ✅ 已知（Selberg ≅ Weil 顯示公式）|
| **自伴隨擴張唯一性** | ❌ **真正的缺口** |

- **函數方程 = 算子的骨架**
- **Euler 乘積 = 算子的邊界條件（Dirichlet 邊界）**

### 發現 5：Lee-Yang 的翻譯字典

| 統計力學 | 黎曼 ζ 函數 |

**關鍵洞見**：Epstein zeta = 兩個鐵磁系統的疊加 = 自旋玻璃態 = 零點散開

### 發現 6：Φ(u) > 0 來自函數方程，不來自 Euler 乘積

- ξ 函數的 Fourier 核 Φ(u) > 0 ✅
- Epstein zeta 的 Φ_Epstein(u) > 0 **同樣成立** ✅
- **因此**：Φ(u) > 0 只保證「是一個正常的熱傳導系統」，不保證 Λ = 0
- 真正的區別是零點的**微觀斥力**，不是 Φ 的正性

### 輪 12：文獻精讀——偶特徵函數定理的精確條件（Perplexity Pro 執行）

**【重大發現】Even-Simple 是假設，不是定理**

Connes-van Suijlekom 2025 (arXiv:2511.23257) 的結論需要**四個條件合取**：
1. 二次型下有界自伴
2. 最低譜值 simple 且 isolated
3. 最低態為 even（偶對稱）
4. Toeplitz / spectral-action 型矩陣結構

核心機制：Carathéodory-Fejér 定理

$$T \text{ 為半正定 Hermitian Toeplitz 矩陣}, \dim \ker T = 1 \implies P_\xi(w) = \sum \xi_j w^j \text{ 的根在 } |w|=1$$

透過 $w = e^{i\alpha z}$ 映射：$|w|=1 \iff z \in \mathbb{R}$

**偶性的作用**：不是「魔法般」把根壓到實軸，而是確保最低特徵向量在 even sector，滿足 self-inversive 對稱，使 Carathéodory-Fejér 適用。

**論文現狀精確分類**

| 性質 | 固定有限 (λ,N) | 全體 (λ,N) |
|---|---|---|
| 特徵值 isolated | ✅ 自動（有限維矩陣）| ✅ |
| 最低值 simple | 可數值檢查 | ❌ 作為假設 |
| 最低向量 even | 需額外確認 | ❌ 作為假設 |
| D_log^(λ,N) 自伴 | ✅ 在 even-simple 前提下 | ❌ 條件式 |

**關鍵公式（整函數層級的目標）**

$$C_{\lambda,N}(z) \cdot \det_{reg}\!\left(D_{\log}^{(\lambda,N)} - z\right) \xrightarrow{?} \Xi(z) \quad \text{（局部一致收斂）}$$

因為 $\det_{reg}(D_{\log}^{(\lambda,N)} - z) = -i\lambda^{-iz} \hat{\xi}_{\lambda,N}(z)$，所以這等價於 $\hat{\xi}_{\lambda,N}(z) \to \Xi(z)$（正規化後）。

### 輪 13：增量算子 $\Delta D$ 的代數解析（Gemini Pro 執行）

**增量算子解析形式**：

$$\Delta D = D_{\log}^{(\lambda_{k+1},N)} - D_{\log}^{(\lambda_k,N)} = \sum_{\lambda_k^2 < n \le \lambda_{k+1}^2} \Lambda(n) \cdot \Pi_N (V_n + V_n^*) \Pi_N$$

對測試態 $\xi$：

$$\langle \xi, \Delta D \xi \rangle = \sum_{\lambda_k^2 < n \le \lambda_{k+1}^2} \frac{\Lambda(n)}{\sqrt{n}} \int |\hat{\xi}(\omega)|^2 \cos(\omega \ln n) \, d\omega$$

- **充要性**：$\Lambda(n) \ge 0$ 保證廣義正定核權重全正 $\implies \Delta D \ge 0$（PSD）。
- **Epstein 測試**：$Z_E(s)$ 缺乏單一 Euler 乘積，對數導數展開係數 $a_n$ 存在負值 $\implies \Delta D_{\text{Epstein}}$ 產生負定分量，特徵值劇烈震盪。
- **🛑 重大死路**：$\inf_k \Delta\mu_k \ge \delta > 0$（均勻常數下界）**數學上不可能**！因為 $\mu_{\min} \to \gamma_1 \approx 14.1352$ 收斂，故 $\Delta\mu_k \sim O(p_k^{-2})$ 必須趨近於 0 且級數收斂。

### 輪 14：Groskin 2026b 精讀與收斂 6 步地圖（Perplexity Pro 執行）

**有限 Guinand-Weil 字典（精確恆等式）**：

$$\langle v, Q_\infty v \rangle = \sum_{z \in Z_\zeta^*} g_v(z) = Q_{\text{prime}}^{(c)} + Q_{\text{pole}} + Q_{\text{arch},\infty}$$

- $g_v$ 是 band-limited 整函數，$\operatorname{supp} \hat{g}_v \subset [-\frac{\log c}{2\pi}, \frac{\log c}{2\pi}]$。
- Archimedean 尾項 $\Delta_{T_1, T_2}$ 具有 rank-2 density 的 Cauchy-Stieltjes 嚴格全正（totally positive）結構。
- 誤差算子界：$0 \preceq Q_\infty - Q_{\text{tot},T} \preceq B_T I$，其中 $B_T \sim O(\frac{N \log T}{T})$。
- **定位**：Groskin 2026b 是「修正第 0 步」（排除實位積分截斷偽影），不直接給出 $(c,N) \to \infty$ 的 minimizer 收斂。
